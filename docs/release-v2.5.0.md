# v2.5.0：双圈速度与秒差分析

2026-10-03。

## 使用

加载至少两圈完整 GPS 与视频记录后，打开「双圈对比」。页面沿用主界面的深灰背景、细边框和橙色强调色；上方为两个视频，下方左侧是紧凑行车线，右侧是速度与时间差曲线。A 为蓝色参考圈，B 为橙色对比圈。

图表横轴为 A 圈行驶距离，速度曲线同时显示两圈到达对应位置时的速度。悬停显示 A/B 用时、速度、速度差和 delta；点击或拖动会暂停播放并定位两个视频和地图标记。方向键可移动位置；＋／－缩放区段，「全圈」恢复范围。速度单位跟随系统的 km/h / mph 设置。手机采用纵向布局。

默认「同位置分析」以 A 圈为主时间轴，调整 B 视频播放节奏以匹配对应赛道位置，两路静音。「同时间回放」保留原先按冲线后经过时间播放的方式，A 有声音，B 静音。两种方式下图表的 delta 都按对应位置计算。

## delta 与位置匹配

`delta = B 到达对应位置的用时 − A 到达该位置的用时`。红色正值表示 B 更慢，绿色负值表示 B 更快；冲线起点为零，终点等于完整圈时差。局部得失由实际 GPS 时间插值得到，整圈差值不会平均摊到曲线上。速度差同样定义为 B − A。

各圈重采样为 601 个距离点，再在相邻进度范围内投影匹配 B 轨迹；匹配同时考虑行驶方向，并约束 B 的对应进度不倒退，减少发卡弯附近直道的误匹配。轨迹匹配的中位误差超过 20m、95% 分位误差超过 50m，或两圈长度比例超过 1.5 时，改为距离比例估算并显示警告。无效或空 GPS 禁用位置分析，仍可同时间回放。

GPS 采样频率、漂移、走线差异和视频时间偏移都会影响局部比较精度；这属于分析估算，不是官方测量或专业计时精度保证。同位置回放中 B 的节奏可能变化，超出播放速率范围时会以位置校正补偿，双路 4K 的流畅程度取决于设备解码能力。

## 官方资料参考

- [RaceChrono：按位置对齐圈比较](https://racechrono.com/forum/d/1305-1305)：对应刹车点等位置比较适合位置对齐，单纯比例缩放可能错位。
- [RaceChrono：位置与时间对齐差异](https://racechrono.com/forum/d/2148-2148)：同位置视频比较与真实经过时间回放用途不同。
- [AiM Race Studio 3 分析手册](https://www.aim-sportline.com/docs/racestudio3/manual/html/analysis.html)：参考地图、速度曲线和时间／距离分析联动的组织方式。本版不声称复现其内部计算算法。

## 验证

- 自动回归覆盖零秒差、正负符号、终点真实圈时差、位置／时间插值、单调匹配、局部先慢后快、轨迹不一致降级、无效距离、空 GPS 和距离平台；同时运行已有分圈、主题与磁盘写入检查。

- `npm test`、`npm run build:check` 通过。浏览器未出现未捕获错误。
