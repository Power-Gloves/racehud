# 项目审查与功能补齐记录

日期：2026-09-11。目录及数据模型见根目录 `CONTEXT.md`。本次没有提交、推送或部署，旧 ZIP 不包含本次修改。

## 结论

实际运行核心是 `04-前端应用`，不是后端。两个工作模式共用 App、HUD、时间轴和导出器；差异主要来自数据导入后是否建立自动分圈源。外置数据以前直接 setData，绕过了起跑线/重新分圈处理。部分用户观察到的差异还来自共享导出逻辑的错误。

## 本次修复

1. **构建失败**：App 引用了未导入的 ExportSettings，并将函数传给只接受设置对象的回调。改成唯一设置状态，删除重复导出范围状态。
2. **导出偏移方向相反**：预览、单圈范围、时间轴高亮、导出 HUD 现共用可逆换算。非零偏移时原结果错误，零偏移会掩盖问题。
3. **重新分圈重置对齐**：初始化只跟随数据源变化，滑块重算不触发媒体起点重置。
4. **外置数据缺少起跑线和 VBO 分圈**：新增共用 prepareTelemetry；保存不可变原始数据，以支持恢复设备圈号。
5. **文件切换/清除后的异步覆盖**：导入与对齐结果检查版本，旧 Worker 可终止；更换 GoPro 视频会重新提取。外置模式移除视频保留 GPS。
6. **圈时少一个采样间隔**：完整圈结束取下一圈真实起点；当前圈查询采用左闭右开区间，消除圈间空隙。
7. **尾部残圈误当最佳圈**：无结束过线证据的最后一段不参与最佳圈；自动秒差的完整圈判定同步改用过线数组。
8. **低速/高采样率漏圈**：删除每采样点必须移动 0.5 米的限制，防抖由点数改成 2 秒；按线段相交位置插值过线时刻。
9. **无效自动对齐**：短数据、平直信号、非法时间戳不再作为正常成功结果；低评分/低置信度保留原偏移。
10. **预览/导出插值不一致**：共用 interpolateSampleAt，正确处理航向绕回及跨圈计时。
11. **导出强制 60fps 帧时长**：改用输入帧的真实时长，首尾按选定范围裁剪。音频使用相同时间原点和采样级裁剪，保留时间间隙。
12. **浏览器 AAC 编码不可用**：先探测实际音频配置，优先 AAC，不可用时回退 Opus；都不可用则明确失败。Opus-in-MP4 对旧播放器的兼容性仍需注意。
13. **无效范围/资源释放**：拒绝倒置、非有限或无重叠范围；取消/失败释放编码及输入资源。
14. **发布检查遗漏**：CI 加入回归测试和严格构建，以免仅 Vite 打包掩盖 TypeScript 错误。
