# v2.3.0：长视频磁盘导出与简约配色主题

2026-09-29。

## 长片导出修复

旧版使用内存输出目标，默认将所有编码媒体留在内存，到导出结束再生成完整 MP4 缓冲和 Blob。即使选择 0–700 秒，只要该范围的输出较大，仍可能耗尽浏览器内存。解码还会为每帧新建画布，增加显存分配压力。

新版改用磁盘流式输出、2 MiB 写入分块、普通 MP4 尾部元数据和两个循环复用的解码画布。编码结果逐块写盘，不再在 JavaScript 堆里累积完整视频。[Mediabunny 官方输出说明](https://mediabunny.dev/guide/writing-media-files) 说明了内存目标与流式目标的区别；实际实现按项目锁定版本的 API 编写。

在支持保存选择器的 Chrome / Edge 中，点击导出后先选择 MP4 保存位置，随后直接写入磁盘。成功才提交文件，取消或失败会放弃未提交写入。其他支持 OPFS 的浏览器先写私有磁盘，再提供下载；仍需足够磁盘空间。JS 内存不再与编码文件大小一起线性增长，但解码器、GPU、元数据仍会占用内存。

普通 MP4 的元数据位于末尾，因此文件需要完成后才能播放；不使用兼容性较弱的碎片化 MP4。保持原有分辨率选项、音轨、按圈范围和红灯功能。

## 三个简约新主题

| 主题 | 设计 |
| --- | --- |
| 蓝白航线 | 蓝色速度舱与白色计时舱，圆角、细描边、共用基线 |
| 薄荷留白 | 深绿透明模块、薄荷细刻度、对角布局与轻量轨迹 |
| 珊瑚刻线 | 暖色速度铭牌、中央计时坞、珊瑚色轨迹与独立秒差 |

现在共十二个主题，原有极简和两个 DSK 继续保留。新主题共用既有时间、单位和轨迹计算，不将行车线距离添加到导出画面。

## 验证范围

使用用户麦浪 MP4（8,884,440,999 字节）和 DLAP 检查长片导出。旧实现记录到导出约 315 秒时 JS 堆约 536 MB；该轮被开发热更新中断，因此不把它描述成已完整复现用户的浏览器 OOM 崩溃。

新增存储回归通过实际 MP4 复用器验证：结束前已经分块写盘、成功后提交、取消不提交、磁盘写入失败能释放资源。原十二组回归继续保留。三个新主题经过实拍背景可读性及回拖像素一致性验证。

用户已反馈新版成功导出，仍反馈压制速度较慢；本次保留已成功使用的流程。音视频按五秒窗口交替处理，时间戳始终相对于整个导出起点，避免整条轨道处理期间另一编码器闲置被回收。重复解码窗口的性能优化仍待后续处理。自动长片试验未获得完整最终验收结果，不宣称全部长片场景已验证。

三个主题按用户反馈进一步缩小面板、统一圆角与信息基线、调整色彩及细节，并再次通过麦浪实拍背景绘制与回拖一致性检查。长片 4K、不同浏览器和所有硬件组合不属于本次全面验收范围；现有其他计算/格式边界见项目审查清单。
