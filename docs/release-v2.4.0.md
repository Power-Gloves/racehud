# v2.4.0：双圈对比、冲线灯与播放优化

2026-10-02。

## 双圈对比

载入同一场比赛的视频和 GPS 后，顶部「双圈对比」会在至少两圈完整记录可用时启用。A、B 两圈分别选取视频中对应的片段，以各自冲线为零点同步播放；可以暂停、拖动共同进度、切换圈号。两路视频共用原本的本地视频文件，右侧画面静音，避免双重音轨。

下方在同一米制投影和缩放下叠加两条 GPS 行车线，显示两个实时位置、圈时、全程距离、当前已行驶距离、速度和路程差。纵向赛道会把两条线路一起旋转，充分利用屏幕宽度；两圈之间不做独立缩放。圆点按「冲线后经过的时间」移动，因此快慢圈的圆点不一定同时到达同一弯道。GPS 距离和走线受设备定位误差影响，不等同于赛道官方测量长度。

无下一次冲线证据的尾段、GPS 不完整或视频没有覆盖的圈不列入对比。对比页仅供本地查看，不改变原视频、时间轴导出选择或导出 MP4 格式。双路 4K 视频能否流畅同步仍取决于浏览器与设备解码能力；解码不可用时可暂停并拖动查看位置。

## 五盏红灯

灯架设计尺寸由 540×110 缩至 360×80，位置调整为画面水平居中、上方 18%，降低整体及底板不透明度。五灯逐盏亮起、冲线熄灭及 450ms 退场的时间规则保持不变。预览与导出继续调用同一个 `renderHud` 绘制入口。

## 播放与加载

圈表和最佳圈只在轨迹样本变化时派生；播放时按当前 GPS 时间寻找所在圈。时间轴每圈距离也只随轨迹和圈表变化计算，不再每帧计算全部圈。GoPro 视频、DLAP 设备圈号、移动起跑线和当前圈高亮规则保留。

外置 GPS 模式中，解析 DLAP/VBO 与加载视频改用独立的异步版本号。快速先选数据再选视频时，视频加载不再把尚未结束的数据解析判为过期；切模式、移除文件仍会使对应旧任务失效。

## 验证

- `npm test`：原有 15 项加双圈完整性、时间换算和视频覆盖回归通过。
- `npm run build:check`：TypeScript 与 Vite 生产构建通过。
- HERO13 实拍视频：双圈界面打开、两个视频同时播放、拖动后继续同步、切换圈号回到冲线起点；轨迹两线可见，关闭后返回原界面。
- 麦浪 DLAP（23,356 点）与同场 2070.165 秒视频：外置模式快速连续选择两个文件，数据均保留，出现 22 个可对比完整圈。
- 浏览器画布检查：红灯绘制范围约 x=779–1140、y=153–235（1920×1080 设计画布）。实际 GoPro MP4 截取 2 秒并重新编码/解码，输出 2.005333 秒、480,425 字节，顶端可检测到红灯像素。

导出器的五秒音视频交替窗口及保存流程本版未改动。长片压制速度仍有优化空间；本版不宣称完成全长 4K 双路播放或所有机型验证。
