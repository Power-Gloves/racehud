# 六套 HUD 主题重做

用户要求：保留极简及两款 DSK，淘汰其余廉价、同质化的视觉；参考 Foxlap 组件的组织方式，制作六个布局有明显差异的新主题，更新文档并发布到 GitHub。用户明确要求自主完成，无需等待其休息期间确认。

参考：https://foxlap.com/telemetry_overlay.php 。只借鉴模块层级、读数可辨性及仪表组合，不复制其代码、商标或图片。

## 现状问题

旧 JDM 与赛道荧光主要是同一五角布局换色；旧霓虹大量发光降低实拍可读性；旧 F1 的数字间距与文字尺寸缺少严格约束。主题选择器仅有色块，无法判断布局。新主题需要用真实夜间/日间画面审查，不凭空背景评价。

## 六个方向

| ID | 名称 | 构图与性格 |

## 数据及交互边界

所有新主题仅使用真实 GPS 速度、圈内用时、圈号、秒差、G、轨迹和航向。没有 RPM、档位、油门输入时不伪造这些读数。行车线距离仍只在系统界面，不进入任何导出主题。

共用底层图形工具但独立编排。所有绘制函数无时间累积状态，预览、倒退、导出相同时间得到相同结果；轨迹几何与全局刻度以 samples 引用弱缓存，避免每帧扫描整段录像。非有限读数显示占位。

保留原极简/DSK绘制代码。旧四主题从选择器下架，旧 ID 映射到接替主题。选择器以真实 Canvas 缩略图展示新布局；DSK 使用静态布局示意以免其历史全局动画状态被缩略预览污染。

使用自托管开源字体，保留许可证；导出与预览等字体加载完毕再画。新主题给冲线红灯保留画面上部中央区域。
