# 长片导出内存修复与简约主题

用户已要求直接修复、验证并重新发布。沿用已有自主执行授权，不增加设计确认步骤。

## 诊断与方案

麦浪素材 MP4 为 8,884,440,999 字节。现有导出用 BufferTarget，库会默认使用 in-memory fast start，保留所有编码媒体到结束；最终还会建立完整输出 Buffer 和 Blob。CanvasSink 未启用画布池，每帧新建画布。

比较三种方案：缩短导出仅能延后内存上限；限制码率会改变画质但仍随时长增长；磁盘 StreamTarget + fastStart:false 从根本上移除完整编码媒体内存缓存，选用第三种。普通 MP4 元数据置于文件末尾，保留普通 MP4 结构；不引入兼容性更弱的 fragmented MP4。

支持保存选择器时，先选择文件，再逐块写盘。取消/失败 abort 暂存写入，只有成功才 close 提交文件。其他支持 OPFS 的浏览器使用私有磁盘临时文件，再触发下载并释放。磁盘空间不足应提示清理空间。解码复用两个画布，编码逐帧 await 保持背压。

## 验证

对实际麦浪素材导出 0–700 秒，记录进度与 JS 堆；重新打开结果检查首中尾帧、音轨和时长。额外验证非零起点、取消、写入失败清理。注意 JS 堆不等于浏览器全部 GPU/进程内存，不能声称内存完全恒定。
