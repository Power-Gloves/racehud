# 单圈冲线红灯

用户已选择五盏红灯方案。适用于 GoPro 与外置 GPS 两种模式，单圈导出时默认开启，可关闭。

- 以所选圈的起点为熄灯时刻，使用现有 GPS/视频偏移换算。
- 冲线前最多 5 秒依次点亮五灯。前置缓冲不足 5 秒或视频起点截断缓冲时，缩短点灯周期以覆盖实际可用时间。前置缓冲为 0 时不显示。
- 五灯在冲线瞬间一起变暗，灯架短暂停留后淡出（总计 450ms），不播放声音。
- 画面上部中央绘制独立 Canvas 叠加层，所有主题复用。
- 仅所选单圈起点触发；整个视频、自定义范围及未选圈不显示。
- 状态只由当前时间推导，暂停、快进、倒退不会积累动画状态。预览与导出使用同一绘制入口。
- 验证：点灯边界、冲线熄灭、短缓冲、零缓冲、无重叠、正负偏移、拖动回退，以及实际浏览器预览/编码帧。

实现顺序：纯函数与回归 → 共用绘制层 → 单圈设置接入 → 浏览器验证 → 更新日志。
