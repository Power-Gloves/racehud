# RaceHUD v2.2.0 更新说明

2026-09-11。本次更新以六套新 HUD 主题为核心，同时发布此前完成的 DJI + 外置 GPS 功能补齐、冲线红灯和行车线距离。

## 六套新主题

保留「极简」「DSK专属」「DSK专属（无圈速版）」的原有视觉。旧霓虹、F1、JDM、竞技四项退出主题选择器，替换成六套不同布局，现在共九项。

| 主题 | 布局与视觉 | 适用偏好 |
| --- | --- | --- |
| 极点转播 | 左上角转播记分牌、左下朱红切角速度块、附属秒差条，右侧赛道与 G 表 | 喜欢赛事转播的强对比、速度优先 |
| 精密计时 | 底部中央冷银模拟速度表，圈时与最佳圈分列两侧；赛道与 G 表靠边 | 喜欢实体仪表和对称构图 |
| 拉力路书 | 左侧琥珀色纵向数据塔，右上朝北赛道图，右下航向牌 | 喜欢路书、导航和纵向阅读 |
| 耐力工程 | 底部统一数据带：速度、圈时、最佳圈、秒差、G 表、最近 8 秒速度曲线 | 希望数据齐全且方便横向比较 |
| 轻量尾流 | 大号裸排数字、酸柠绿细刻度、底部轻渐暗，保留大量画面 | 喜欢轻量、少面板、突出原视频 |
| 经典勒芒 | 奶油白模拟表盘、暗红双线、衬线圈时铭牌 | 喜欢复古赛车和机械计时风格 |

参考了 [FoxLAP Overlay Studio](https://foxlap.com/telemetry_overlay.php) 的组件层级、刻度仪表和留白方式；新主题使用本项目独立编写的 Canvas 绘制代码，不引入其源码或素材。

### 交互和实现

- 主题选择器从「颜色 + 88」改为实际布局缩略图，并附简短风格说明。DSK 使用明确标注的布局示意，避免调用其有历史状态的绘制函数污染真实预览。
- 新主题使用随包提供的 Barlow Condensed、IBM Plex Mono、Bitter 字体，附 SIL OFL 许可；导出前等待字体就绪，不依赖 Google Fonts 网络加载。
- 新主题预览与导出共用绘制函数；动画不依赖上一次播放状态，向前播放、回拖、单独导出均按当前时间计算。
- 圈时来自统一圈边界与播放时刻；处理毫秒进位、km/h / mph 换算、缺失值。速度、G、航向来自真实遥测，不生成不存在的转速、挡位或油门数据。
- 新赛道图缓存 GPS 路径，并按纬度修正经度比例；支持显示当前车点和起跑线。新主题没有把行车线距离加入 HUD。
- 兼容旧主题标识：neon → 轻量尾流，f1 → 极点转播，jdm → 拉力路书，race → 精密计时。

## 同批发布的功能和修复

- DJI + DLAP/VBO 共用起跑线调整、重新分圈、主题和按圈导出流程；DLAP 默认保留设备圈号，Auto 可恢复。
- 调整起跑线保留视频播放位置和对齐偏移；旧导入、旧自动对齐任务不再覆盖新的文件状态。
- 修正预览与导出的非零时间偏移、圈结束边界、尾部残圈参与最佳圈以及高采样率低速漏圈。
- 单圈起点前最多五秒逐盏亮起红灯，过线同时熄灭。前置缓冲较短时压缩点灯周期；提供开关。
- 时间轴显示每圈行车线长度和当前圈已行驶距离，尾部片段标注「已记录」。这是 GPS 行车路径估算，不是场地面积，也不是官方赛道长度。
- 导出采用真实输入帧时长和统一音视频裁剪起点；浏览器无法编码 AAC 时回退 Opus。

## 验证

- 12 组确定性回归通过，覆盖圈边界、低速分圈、时间偏移、信号校验、设备圈号恢复、红灯边界、圈距离、新主题计时/单位及旧主题兼容。
- TypeScript 严格检查与 Vite 生产构建通过。仍有大编码模块分块提示，不影响构建完成。
- 六套新主题均用宜昌 DJI 实拍 + 同场 DLAP 绘制，检查静止和行驶画面、空数据、异常数值、mph 模式。白天 GoPro 画面另用于高亮背景可读性检查，该组设计对照不作为遥测同步验证。
- 两种模式分别导入真实 DLAP / GoPro，九个主题逐项切换通过。六个新主题经过回拖、跳播后再次绘制同一时刻，像素完全一致；冲线红灯所需的上方中央区域没有主题元素遮挡。
- 六套新主题均实际编码并重新解码 MP4：截取 350.0–351.2 秒，输出 1280×720，有音轨；容器时长均约 1.216 秒（含音频编码边界）。检查了解码后的主题画面。
- 前序同场实测：Action 4 自动对齐偏移 272.68 秒；第 1 圈 89.37 秒，加前后各五秒后实际导出约 99.371 秒。HERO13 Black 实拍提取 5,260 GPS 点、10 个完整圈。
- 前序红灯实测：实际导出并解码检查，冲线前依次为 1/2/3/4/5 盏，过线为 0；系统圈长约 945 米。

## 使用和发布

本地在 `04-前端应用` 执行 `npm ci`、`npm run dev -- --host 127.0.0.1`，访问 `http://127.0.0.1:5174/`。右侧设置的主题缩略图可直接切换。

推送 `main` 后，GitHub Actions 执行回归、严格构建并部署 GitHub Pages。部署结果以实际工作流为准；线上页面应显示 v2.2.0。

## 尚未解决的边界

本次保留了 DSK 原主题，未重写其历史动画状态和独立最佳圈计算。VBO 跨午夜、非 16:9 / 旋转预览与导出一致性、固定 30fps 步进、长视频 4K 内存等问题仍列在 [项目审查清单](project-audit.md)。当前实拍不能代表全部 DJI 型号；Opus-in-MP4 在旧播放器中可能不兼容。

模拟速度表固定量程为 0–160 km/h 或 0–100 mph；超量程时指针到顶，数字继续显示真实速度。G 表范围为 2G；工程速度趋势纵轴为 0–160 km/h。新布局按 16:9 设计。
